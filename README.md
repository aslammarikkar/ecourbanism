# UrbanCool AI

Live site: **https://oshinit.github.io/ecourbanism/**

A responsive urban heat-mitigation decision-support prototype built with React, Vite, TypeScript, Material UI, Recharts and Leaflet/OpenStreetMap.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:5173`).

## Production check

```bash
npm run build
npm run preview
```

All city, neighbourhood, AI-agent, scenario and sensor values are local mock data. The application does not connect to live sensors, external AI models, paid services or scientific prediction APIs.
